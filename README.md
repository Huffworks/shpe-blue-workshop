# Context and Creating: workshop kit

This is the attendee kit page for the Blue workshop, "Context and Creating", at the SHPE DFW "AI for Engineers" event on 2026-10-17. The page is at https://huffworks.github.io/shpe-blue-workshop/.

The page holds everything an attendee pastes during the hands-on: a five-line Project instructions template, a brand kit, three sample engineering documents, five prompts, example rules and stretch cards. The Files section has the same material as Markdown and Word files, the two decks the live demo produces, the system diagram, the one-page cheat sheet and the workshop slides.

Every company, person and document on the page is fictional. The site is one static page plus a files folder. It is rebuilt from the workshop's source files and pushed here, so edits made directly in this repository get overwritten on the next push.
